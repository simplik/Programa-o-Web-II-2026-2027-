RESPOSTAS DAS QUESTÕES TEÓRICAS DA LISTA 01;

01)

a)Uma linguagem de tipagem estática é caracterizada por: quando você precisar declarar um tipo de dado no código, ele vai permanecer o mesmo e só receberá um valor que seja do tipo específico do dado declarado.

b)A tipagem estática é boa, pois ela permite um melhor entendimento, já que nela o código fica mais claro e explícito, então é melhor entender o próposito de cada função, variável e etc. O compilador também ajuda quando houve um erro no código, já que o código é verificado antes mesmo de rodar em si.

c)A tipagem dinâmica, ao contrário da estática, funciona verificando os tipos de dados enquanto o código roda, fazendo com que uma variável possa receber um valor diferente ao longo do código.

d)A diferença das duas é que, enquanto na tipagem forte, a linguagem dificulta a realização de operação entre tipos de dados diferentes, evitando essas conversões ao longo das situações do código; Enquanto a fraca, permite que isso aconteça de maneira fácil.

e)As linguagens híbridas geralmente vão combinar o que há de melhor em cada tipagem, podendo ser rigida e flexível em determinadas situações. Isso tudo é permitido com a inferência de dados, que já busca o tipo de uma variável dependendo do valor atribuído a ela, sem que precisem informar antes.

f)O Javascript lida com isso tendo uma tipagem dinâmica, onde o tipo de uma variável pode ser determinado só pelo valor que ele recebe, podendo mudar durante o funcionamento do código.
